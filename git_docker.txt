🚀 Cách deploy

Build frontend tại local:

cd /root/projects/smart-react-vite-final
npm install
npm run build


→ tạo ra thư mục /root/projects/smart-react-vite-final/dist

Build & run toàn bộ stack:

cd /root/projects/build-docker
docker compose down -v
docker compose build
docker compose up -d


Kiểm tra:

docker ps
docker logs nginx --tail=50
docker logs backend-spring --tail=50
