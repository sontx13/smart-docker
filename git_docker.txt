⚙️ CÁC BƯỚC CHI TIẾT
🧱 1. Dừng container backend cũ
cd /root/projects/build-docker
docker-compose stop backend-spring

📦 2. Cập nhật code backend mới nhất
cd /root/projects/smart-java-spring-final
git pull origin main


⚠️ Nếu bạn gặp lỗi kiểu “You have unstaged changes” thì dùng:

git reset --hard HEAD
git pull origin main

☕ 3. Build lại image backend
cd /root/projects/build-docker
docker-compose build backend-spring


Dòng này sẽ chạy lại Dockerfile trong smart-java-spring-final
→ chạy gradle clean build -x test → tạo JAR → copy qua image.

🚀 4. Khởi động lại backend mới
docker-compose up -d backend-spring

🔍 5. Kiểm tra lại container
docker ps

🚀 CÁCH TRIỂN KHAI BUILD FRONTEND LOCAL → SERVER (Nginx Docker)
🧩 1. Build ở local

Tại thư mục dự án React/Vite trên máy bạn:

npm run build-uat


Khi xong, bạn sẽ có thư mục:

smart-react-vite-final/dist/


Đây là toàn bộ file tĩnh (HTML, CSS, JS, hình ảnh...) sẵn sàng để deploy.

cd ../smart-react-vite-final/

git pull

Bước 4. Restart lại nginx container
 cd ../build-docker/
docker-compose restart nginx

nên khi bạn ghi đè dist, Nginx sẽ tự đọc bản mới luôn.
